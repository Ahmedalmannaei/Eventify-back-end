# 🎉 Eventify - Backend 🚀

Welcome to **Eventify**, a web application that allows users to create, view, and comment on events. This repository contains the **backend** built with **Node.js**, **Express.js**, and **MongoDB**. 🖥️✨

## 🏆 Project Overview

**Eventify** backend powers the frontend application by providing:

- 🔗 REST API endpoints for events, comments, and user authentication
- 🔐 JWT-based authentication and protected routes
- 📦 CRUD operations for events and comments
- 👥 Role-based access (owners can edit/delete their own content)

The backend is connected to **MongoDB** and handles all data storage and retrieval for the frontend.

---

## ⚡ Features

- 🔑 User Authentication (Sign up / Sign in)
- 🚧 Protected Routes for logged-in users
- ✏️ Event CRUD operations
- 💬 Commenting system
- 👤 Role-based access control for users
- 🗄️ MongoDB database integration
